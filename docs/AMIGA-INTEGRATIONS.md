# Amiga museum integrations

Amiga integrations share a preservation-first, assisted contract. Product distributions, Kickstart, AmigaOS media, golden images, and living state are separate objects with separate rights and backup expectations. Commercial platform assets are always user-supplied or licensed-private and are referenced from operator-controlled storage rather than copied into Git.

Generic helpers resolve prerequisites, emit configurable FS-UAE profiles, create working images once from qualified golden images, and use FS-UAE's raw TCP serial bridge. M5 owns emulator process mechanics, M3 lifecycle/maintenance holds, and M4 route authorization and streams. The product module owns guest installation instructions and qualification evidence.

This model does not assume an archive format, a host-side installer, native Linux, an unattended setup, or a guest TCP service. AmiExpress can reuse it while retaining its own artifacts, installation steps, mutable paths, and qualification checks.
