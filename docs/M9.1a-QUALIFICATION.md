# M9.1a real DOSEMU2 + FreeDOS qualification

## Result: INCOMPLETE

Real binary-safe COM1 qualification passed on 2026-08-17 in the disposable
Debian 13.6 x86_64 VM using DOSEMU2 2.0pre9 revision 7076 and FreeDOS 1.4
kernel 2043. M9.1a nevertheless remains incomplete because its original
acceptance contract also requires clean stop/restart and at least two isolated
instances. Those lifecycle and multi-instance checks were deliberately not
performed in this M9.1a byte-transport continuation.

## Real VM evidence

The repository DOS probe was rebuilt with NASM from source after verifying all
three MATRIX corrections: `recv_one` no longer destroys the outer `CX` count,
the short command-tail length is accepted, and mode detection checks `M` at
PSP offset `82h`. The run used fresh 1.44 MiB `mkfatimage16` images, offline
`mtools` inspection at offset 8832, a raw host PTY, and COM1 only.

| Gate | Host observation | Guest FAT-image record | Result |
|---|---|---|---|
| SELFTEST | headless FreeDOS execution | `MODE=SELFTEST`, `EXECUTION=PASS`, `WRITE_PATH=PASS`, `RESULT=PASS` | PASS |
| Basic COM1 | TX 3 bytes `414243`; RX 6 bytes `5542422D4F4B` | `RX=414243`, `TX=5542422D4F4B`, both statuses PASS | PASS |
| Minimal binary | TX/RX 3 bytes `0041FF` | `RX=0041FF`, `TX=0041FF`, both statuses PASS | PASS |
| Raw matrix | TX/RX 13 bytes `00010A0D1B20417F80B3C4DAFF` | exact RX/TX, both statuses PASS | PASS |
| Combined matrix | TX/RX 23 bytes `00010A0D1B20417F80B3C4DAFF1B5B33316D0D0AB3C4DA` | exact RX/TX, both statuses PASS | PASS |
| Basic repeatability | ten fresh runs | ten exact guest result records | PASS (10/10) |
| Combined repeatability | three fresh runs | three exact guest result records | PASS (3/3) |

The matrix proves NUL (`00`) and `FF` host-to-guest and guest-to-host. It also
proves CR (`0D`), LF (`0A`), CRLF (`0D0A`), ANSI escape sequence
`1B5B33316D`, and CP437 bytes `B3 C4 DA` without translation in either
direction. The exact combined payload was:

```text
00010A0D1B20417F80B3C4DAFF1B5B33316D0D0AB3C4DA
```

One pre-fix repeatability attempt received the correct serial reply but raced
DOSEMU2 shutdown before `SERIAL.RST` was visible offline. The image runner now
allows a bounded 250 ms for the guest's final FAT result write before shutdown;
the fresh post-fix qualification then passed 10/10 and 3/3.

## Original acceptance contract review

The original contract is recovered from commit `ecbcf69`: preserve an
authoritative FreeDOS artifact through M1; derive an immutable golden
environment and mutable working copy; boot with explicit guest evidence;
exercise COM1 byte-for-byte including CP437, ANSI, and CRLF; test clean
stop/restart and at least two isolated instances; and record filesystem-locking
limitations. Historical BBS compatibility remains `HUMAN_REQUIRED` and is not
a hard completion criterion.

| Original hard criterion | Evidence | Status |
|---|---|---|
| M1-preserved authoritative FreeDOS artifact | Official FreeDOS 1.4 LiveCD was preserved and checksum-verified in the disposable qualification archive | PASS |
| Immutable golden environment and mutable working copy | Preserved/derived boot material was copied into fresh disposable working trees and FAT result images | PASS |
| Real headless boot with explicit guest evidence | FreeDOS 1.4/kernel 2043 plus guest-written SELFTEST execution/write-path result | PASS |
| COM1 byte-for-byte, including CP437/ANSI/CRLF | Exact minimal, raw, and combined bidirectional evidence above | PASS |
| Clean stop/restart | Out of scope for this continuation and not tested | NOT MET |
| At least two isolated instances | Out of scope for this continuation and not tested | NOT MET |
| Filesystem-locking limitations recorded | Product-specific locking remains deferred; no locking claim was made | PASS (limitation recorded) |

Because two original hard criteria are not met, this document does not close
M9.1a. M9.1b and M9.1c remain independently incomplete; their requirements are
not imported into the byte-matrix result above.
