## Clean stop and restart closure

Instance A used `/home/ubbqual/m91a-close/instance-a/drive-c`, FAT image
`instance-a/result.img`, its own HOME/config/log tree, and an independently
allocated raw COM1 PTY. On the first boot, PID `50397` and PTY `/dev/pts/0`
produced guest SELFTEST PASS and exact `414243` / `5542422D4F4B` COM1 evidence.
The established qualification runner's bounded `SIGTERM` path stopped DOSEMU2
in 0.001 seconds with status `-15`; no `SIGKILL` was used. The process vanished,
the PTY node was released after descriptor closure, and both FAT result records
were readable with `mtools`.

Restarting the same isolated working root and FAT image created PID `50427`
(`50397 != 50427`). The released devpts number was safely reused as
`/dev/pts/0`; this was a new PTY lifetime owned by the new process. FreeDOS boot,
SELFTEST, and the exact basic COM1 exchange passed again. The second bounded
clean stop also took 0.001 seconds and left no process or PTY. Therefore
`CLEAN_STOP_RESTART=PASS`.
